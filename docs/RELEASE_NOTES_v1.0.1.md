# WinAudioClean v1.0.1

This patch fixes existing FFmpeg installation discovery from Windows desktop
shortcuts and refreshes the interactive terminal as an original cybernetic
audio console inspired by Ghost in the Shell.

The shared resolver retains explicit path, portable sibling and valid process
PATH precedence. After a miss it reads FFMPEG in process/user/machine scope,
then persisted user/machine Path. FFMPEG may identify a bin directory,
installation root or full ffmpeg.exe path. Quoted paths and bounded persisted
environment references are supported. Selection remains literal, absolute and
local. Invalid explicit or present sibling tools still fail without fallback.
No environment or registry writes, new runtime dependency or bundled FFmpeg.

Interactive SIGNAL CONTROL displays validated engine readiness, numbered Raw
and Zoom actions, real processing stages and a prominent outcome/output path.
It uses the host background, restrained colors and ASCII with narrow-console
support. Expected dependency failures show the reason and a useful next step.

Audio filters, Original 1.0.0 and Gentle 0.1.0 presets, output encoding/naming,
folder layout, settings/report schemas, cancellation, final pause and unattended
requirements remain unchanged. Development reproduction tools recognize the
new application version while preserving the earlier report recipes.

The release ships the existing tool-only ZIP plus SHA-256 and source provenance.
Windows automated acceptance includes extracted BAT Raw/Zoom conversions, direct
PowerShell, shell-link activation from another working directory, exact tool
selection, independent PCM16/48 kHz output validation and source preservation.
Hosted-runner tests also exercise real persisted-user reads with stale process
environments and restore their disposable-account values in finally blocks.
